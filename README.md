# RadioFoundry 简体中文汉化版

**RadioFoundry** 开源对讲机固件的**个人简体中文汉化版**，适用于 **DM-32UV** 对讲机。

> ⚠️ **重要提醒**
> - 这是**个人汉化**的固件，**并非官方中文版本**。
> - **刷机有风险**，可能导致设备损坏或变砖，刷机前请**备份原厂固件**。
> - 刷机后的一切后果由使用者自行承担。

---

## 这是什么

本仓库是 [RadioFoundry](https://github.com/RadioFoundry/RadioFoundry)（MIT 许可的开源对讲机固件）的简体中文汉化版本。
在保持原固件全部功能的基础上，把界面汉化为简体中文（在 **设置 > 显示 > 语言** 中选择 **简体中文**），
并修复了中文（CJK）字符的显示问题（全角字符按 2 格绘制、各字号都有 CJK 字形、字形顶部不再被削掉、文本在字符边界截断）。

| **DM-32UV** | HRC7000（C-SKY CK803S） | 240x320 ST7789 |

## 刷机方法

1. 将对讲机进入刷机模式（黑屏 + 绿灯常亮）。
2. 用刷机工具把固件刷入应用区。
3. 刷完重启，在 **设置 > 显示 > 语言** 中选择 **简体中文**。

> ⚠️ **刷机有风险**：操作不当或固件不匹配可能导致对讲机无法开机。刷机前务必备份原厂固件。
